# Терисбутак, пост 14253: зимняя водообеспеченность

Основной расчёт ДНРЭ по ручью Терисбутак (пост 14253, устье, код ГВК 113200774). Источник суточных расходов: РГП «Казгидромет», ЕДС, часть 1, таблица 1.3, форма А, 2020–2023. Суточный ряд в репозиторий не входит. SHA-256 исходного Excel: `8d4dfbcc0c39de382c6ca2c520dd7f693662c1dfaf38ca2d152d515b780c99ba` (`results/Source_SHA256.txt`).

## Что считается
- `Monthly_Metrics.csv`: по каждому месяцу покрытие, средний расход, минимум с датой, объём.
- `Season_Metrics.csv`: то же для зимних сезонов ноябрь–март (год = год окончания) плюс минимальный средний расход за семь последовательных суток. Полные сезоны 2021, 2022, 2023; сезоны 2020 (91 из 152 суток) и 2024 (61 из 152) неполные и помечены `full_season=False`.
- `Scenario_Balance.csv`, `Deficit_Runs.csv`: сценарный баланс в устье. Сценарный параметр R = Q_эко + q_забор (м³/с), сетка 0,20…0,60 с шагом 0,05. Сутки дефицита: Q < R; объём дефицита: сумма max(0, R − Q) × 86 400. Утверждённого экологического расхода для створа в исходниках нет, поэтому R задан как сценарный параметр, а не норма.
- `Flag_Counts.csv`: пометы Казгидромета (`^`, `_`, `"`) сохранены как в источнике и не использовались для исключения. Их расшифровки в исходном файле нет.
- `A2_input_post14253_winter.csv`: заготовка входа для `a2_winter_minimum.py` (Q_nat по полным зимним месяцам, W_div и Q_min не заданы = ND).

## Проверка
```bash
python terisbutak/winter_flow.py --verify                       # из агрегатов results/Flow_Counts.csv (CI)
python terisbutak/winter_flow.py --raw <файл.xlsx>              # полный расчёт из суточного ряда (локально)
```
Из агрегатов пересчитываются число суток, средние, минимумы, объёмы, число суток и объём дефицита. Минимум за семь суток и непрерывные периоды зависят от порядка суток; для них CI проверяет согласованность (сумма длин периодов = число суток дефицита, длиннейший период). Сверка с суточным рядом выполняется локально.

## Границы применимости
Три полных зимы не дают основания оценивать обеспеченность 95% и не позволяют переносить расход из устья в проектный створ водозабора (для этого нужны координаты створа, площади водосборов и методика переноса). Расчёт описывает наблюдённый зимний сток поста 14253 и чувствительность баланса к заданным значениям R.
